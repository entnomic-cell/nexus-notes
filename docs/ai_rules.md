\# Nexus AI Development Rules



You are modifying a production application.



Rules:

1\. Never change unrelated files.

2\. Prefer smallest possible fix.

3\. Explain reasoning before coding.

4\. Show patch diff before applying.

5\. Preserve architecture patterns.

6\. Ask questions if uncertain.

7\. Do NOT refactor unless requested.

8\. Maintain backwards compatibility.

9\. All features must be modular.

10\. Stability > new features.
